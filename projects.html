Crusader OS

My hobby DIY x86 operating system, written in C and assembly. It went through three versions so far, each one a fresh rewrite as I learned more about OS dev.

Latest and current version, now confirmed to run on real hardware (slowly). It builds on the v02 codebase with a growing SDK, USB 2.0 support (EHCI/OHCI, HID, hubs), a FAT32 driver, AC97 audio playback, task management and BIOS keyboard/scrolling improvements, all while being documented properly this time.

Second, more mature version. Boots via GRUB legacy into a homemade 32-bit kernel, runs in ring 0 and works well in qemu-i386. Has its own filesystem, terminal, keyboard support, a basic GUI and VESA graphics mode. USB, sound, apps and networking are still on the to-do list.

First, now archived version, built for i386 with a custom two-stage bootloader and VGA text output. Made largely by following tutorials and leaning on AI help without fully understanding the underlying C, which is why the project was eventually abandoned and rewritten from scratch as v02.
